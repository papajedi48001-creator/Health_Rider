# เปิด HTTPS ให้ไรเดอร์ทดสอบบนมือถือ (staging)

กล้องสแกน QR, service worker และโหมดออฟไลน์ของไรเดอร์ทำงานเฉพาะบน HTTPS ที่มือถือเชื่อถือเท่านั้น
`compose.yaml` มี service `https` (Caddy) แบบเลือกเปิด ซึ่งออกใบรับรองจาก CA ของ Caddy เอง และต้องติดตั้ง root certificate ของ CA นั้นในมือถือแต่ละเครื่องครั้งเดียว

ใช้สำหรับทดสอบในวง LAN เท่านั้น production ควรใช้ใบรับรองที่ออกโดย CA ของโรงพยาบาลหรือ CA สาธารณะ

## 1. เปิด HTTPS

ใน `platform/.env` ตั้งค่า `HTTPS_HOST` เป็น IP หรือชื่อเครื่องที่มือถือจะเปิด เช่น

```
HTTPS_HOST="172.18.9.98"
```

แล้วรัน

```
docker compose --profile https up -d
```

เปิด `https://172.18.9.98` จากเครื่องนั้นเพื่อตรวจว่าขึ้นหน้าเข้าสู่ระบบ (เบราว์เซอร์จะเตือนเรื่องใบรับรองจนกว่าจะติดตั้ง root certificate)

ถ้ามือถือเปิดไม่ได้ ให้อนุญาตพอร์ต 443 ขาเข้าใน Windows Firewall และตรวจว่ามือถืออยู่ในเครือข่ายที่เข้าถึงเครื่องนี้ได้

## 2. คัดลอก root certificate ออกมา

```
docker compose cp https:/data/caddy/pki/authorities/local/root.crt ./health-rider-root.crt
```

ไฟล์นี้ใช้ยืนยันเว็บเท่านั้น ไม่ใช่รหัสผ่าน แต่ไม่ควรแจกนอกกลุ่มทดสอบ root certificate อายุ 10 ปีและคงเดิมตราบที่ volume `health-rider-caddy` ยังอยู่

## 3. ติดตั้งในมือถือ

**iPhone**
1. ส่งไฟล์ `health-rider-root.crt` เข้ามือถือ (AirDrop หรืออีเมล) แล้วเปิดไฟล์
2. ตั้งค่า > ทั่วไป > VPN และการจัดการอุปกรณ์ > เลือกโปรไฟล์ > ติดตั้ง
3. ตั้งค่า > ทั่วไป > เกี่ยวกับ > การตั้งค่าความเชื่อถือใบรับรอง > เปิดสวิตช์ของใบรับรองนี้

**Android**
1. ส่งไฟล์ `health-rider-root.crt` เข้ามือถือ
2. การตั้งค่า > ความปลอดภัย > การเข้ารหัสและข้อมูลรับรอง > ติดตั้งใบรับรอง > ใบรับรอง CA แล้วเลือกไฟล์

## 4. ทดสอบ

เปิด `https://172.18.9.98` ด้วย Safari หรือ Chrome บนมือถือ ต้องไม่มีคำเตือนใบรับรอง แล้วล็อกอินเป็นไรเดอร์และทดสอบสแกน QR, ถ่ายรูปหลักฐาน และโหมดออฟไลน์

ปิด HTTPS: `docker compose --profile https stop https`
