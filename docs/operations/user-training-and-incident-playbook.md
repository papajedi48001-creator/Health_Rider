# คู่มืออบรมและ Incident Playbook

## หัวข้ออบรม

1. Pharmacy: ยืนยัน candidate, ตรวจโซน/หมู่บ้าน, ออก QR, รับยาคืน
2. Rider: claim ต้องออนไลน์, ห้ามแชร์ QR, offline event จะสำเร็จเมื่อ server acknowledge, หลักฐานต้องหลีกเลี่ยงใบหน้า/ฉลากยา
3. Coordinator: แก้ได้เฉพาะที่อยู่/โทรศัพท์พร้อมเหตุผล; ห้ามแก้ HN/พัสดุ

## รับมือเหตุการณ์

| อาการ | การดำเนินการ |
| --- | --- |
| QR หมดอายุ/claim conflict | ตรวจสถานะ attempt; pharmacy ออก QR ใหม่เฉพาะเมื่อ workflow อนุญาต |
| Offline sync ค้าง | รักษาอุปกรณ์/ข้อมูลไว้, กลับออนไลน์, retry; ห้ามล้าง browser data ก่อนตรวจ queue |
| ส่งไม่สำเร็จ | เลือกเหตุผลมาตรฐาน, return ยาในวันเดียวกัน, pharmacy ยืนยันก่อน retry |
| ข้อมูลที่อยู่ผิดระหว่างส่ง | coordinator แก้ผ่าน amendment พร้อมเหตุผล; ไม่แก้ HN/พัสดุ |
| สงสัยข้อมูลรั่วไหล | หยุดการเข้าถึงที่เสี่ยง, แจ้ง incident owner ตามนโยบาย, เก็บหลักฐานโดยไม่เผยแพร่ผู้ป่วย |
