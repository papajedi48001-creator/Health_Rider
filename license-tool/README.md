# เครื่องมือออก token key ของ Health Rider (ฝั่งผู้พัฒนา)

ใช้บนเครื่องของผู้พัฒนาเท่านั้น ต้องมี Node.js 22 ขึ้นไป ไม่ต้องติดตั้ง package เพิ่ม
private key และสมุดรายชื่อลูกค้า (`ledger.json`) เก็บไว้ที่ `~/.health-rider-license` ไม่อยู่ใน repo

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

```sh
node license-tool/hr-license.mjs keygen
```

1. สำรองโฟลเดอร์ `~/.health-rider-license` ไว้อย่างน้อย 2 ที่ ถ้า private key หาย จะออกหรือต่อ key ให้ลูกค้าเดิมไม่ได้ และห้ามส่ง `private-key.pem` ให้ใคร
2. นำบรรทัด `export const licensePublicKey = '...'` ที่พิมพ์ออกมา ไปแทนในไฟล์ `platform/src/license/public-key.ts` แล้วออกเวอร์ชันใหม่
3. ตั้งแต่เวอร์ชันนั้นระบบจะล็อกจนกว่าจะใส่ token key (ก่อนหน้านั้นทำงานแบบไม่ตรวจ)

รพ. ที่ใช้งานอยู่แล้ว (เช่น วาริชภูมิ) ต้องได้ key ก่อนอัปเดตเป็นเวอร์ชันที่มี public key
ให้ขอรหัสเครื่องจากหน้า **ตั้งค่าระบบ > License** หรือหน้าล็อก แล้วออก key แบบ `lifetime` ให้

## ขั้นตอนกับหน่วยงานใหม่

1. หน่วยงาน deploy ระบบ เปิดหน้าเว็บจะเห็นหน้า login จางๆ พร้อมกล่อง "เปิดใช้งานระบบ" และ **รหัสเครื่อง** เช่น `HR-HGQF-0EDH-H4B8`
2. หน่วยงานส่งรหัสเครื่องมาให้
3. ออก key:

   ```sh
   node license-tool/hr-license.mjs issue --name "โรงพยาบาลตัวอย่าง" \
     --installation HR-HGQF-0EDH-H4B8 --plan yearly --max-riders 20
   ```

4. ส่งบรรทัด `HR1....` ที่พิมพ์ออกมาให้หน่วยงาน วางในกล่องแล้วกด **เปิดใช้งาน** ระบบเปิดทันที

key ผูกกับรหัสเครื่องนั้นเท่านั้น นำไปใช้กับเครื่องหรือฐานข้อมูลอื่นไม่ได้

หรือใช้หน้าเว็บแทนคำสั่ง: `node license-tool/hr-license.mjs serve` แล้วเปิด http://127.0.0.1:4800 (เปิดได้จากเครื่องนี้เท่านั้น)

## ประเภท key

| `--plan` | ใช้ได้ | เตือนล่วงหน้า |
| --- | --- | --- |
| `monthly` | 1 เดือนนับจาก `--start` (ค่าเริ่มต้นวันนี้) | 7 วัน |
| `yearly` | 1 ปีนับจาก `--start` | 30 วัน |
| `lifetime` | ตลอดไป | ไม่มี |

หมดอายุแล้วใช้งานต่อได้อีก 7 วัน (ช่วงผ่อนผัน) จากนั้นระบบล็อก งานส่งยาที่ไรเดอร์ทำค้างไว้ในเครื่องยังส่งเข้าระบบได้

ตัวเลือกเพิ่มเติม

- `--max-riders N` จำนวนบัญชีไรเดอร์ที่เปิดใช้งานได้ เกินแล้วสร้าง อนุมัติ หรือเปิดบัญชีไรเดอร์ใหม่ไม่ได้
- `--max-deliveries N` งานส่งยาต่อเดือน เกินแล้วแจ้งเตือนผู้ดูแลระบบอย่างเดียว ไม่บล็อก

## งานประจำ

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `renew <รหัสเครื่อง> [--plan ...] [--max-riders N] [--max-deliveries N]` | ต่ออายุ นับต่อจากวันหมดอายุเดิม ต่อก่อนกำหนดไม่เสียวัน เปลี่ยนประเภทได้ เช่น `--plan lifetime` |
| `list` | รายชื่อลูกค้าเรียงตามวันหมดอายุ แจ้ง "ใกล้หมด" ภายใน 30 วัน |
| `revoke <เลขที่ key>` | ยกเลิก key (เช่น หลุดออกไป) พิมพ์บรรทัดให้ใส่ใน `platform/src/license/revoked.ts` แล้วออกเวอร์ชันใหม่ |
| `verify <token key>` | ตรวจว่า key ออกจากกุญแจนี้และไม่ถูกแก้ |

ทุกคำสั่งรับ `--dir <โฟลเดอร์>` ถ้าเก็บกุญแจไว้ที่อื่น

## ระบบป้องกันอะไรบ้าง

- **ปลอม key ไม่ได้** key ลงลายมือชื่อดิจิทัล Ed25519 แก้แม้ตัวอักษรเดียวก็ใช้ไม่ได้ และในระบบมีแต่ public key ซึ่งตรวจได้แต่ออก key ไม่ได้
- **ย้ายเครื่องไม่ได้** key ผูกกับรหัสเครื่อง ที่คำนวณจากค่าสุ่มในฐานข้อมูลรวมกับ machine-id ของเซิร์ฟเวอร์
- **ถอยเวลาเครื่องไม่ได้** ถ้าเวลาเซิร์ฟเวอร์ย้อนหลังจากที่ระบบเคยเห็นเกิน 2 วัน ระบบล็อก
- **ตั้ง public key เองผ่าน .env ไม่ได้** public key ฝังในโค้ดตอน build
- ถ้าหน่วยงานได้ source code ไปแก้เอง ก็ยังลบการตรวจออกได้ การป้องกันส่วนนั้นต้องส่งเป็น Docker image ที่ build แล้วแทน source (เฟสถัดไป)
