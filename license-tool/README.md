# เครื่องมือออก license ของ Health Rider (ฝั่งผู้ขาย)

ใช้บนเครื่องของผู้พัฒนาเท่านั้น ต้องมี Node.js 22 ขึ้นไป ไม่ต้องติดตั้ง package เพิ่ม
private key และสมุดรายชื่อลูกค้า (`ledger.json`) เก็บไว้ที่ `~/.health-rider-license` ไม่อยู่ใน repo

## ตั้งค่าครั้งแรก

```sh
node license-tool/hr-license.mjs keygen
```

1. นำบรรทัด `export const licensePublicKey = '...'` ที่พิมพ์ออกมา ไปแทนในไฟล์ `platform/src/license/public-key.ts`
2. build image ใหม่ ตั้งแต่ build นั้นระบบจะตรวจ license (ก่อนหน้านั้นทำงานแบบไม่ตรวจ)
3. สำรองโฟลเดอร์ `~/.health-rider-license` ไว้อย่างน้อย 2 ที่ ถ้า private key หาย จะออกหรือต่อ license ให้ลูกค้าเดิมไม่ได้

รพ. ที่ใช้งานอยู่แล้ว (เช่น วาริชภูมิ) ควรได้ license ก่อนอัปเดตเป็น build ที่มี public key
ถ้ายังไม่ได้ติดตั้ง ระบบจะให้ทดลองใช้ 30 วันนับจากวันแรกที่เปิด แล้วจึงเป็นแบบดูข้อมูลได้อย่างเดียว

## ขายขาด + MA

```sh
node license-tool/hr-license.mjs issue --type perpetual \
  --name "โรงพยาบาลตัวอย่าง" --hcode 10999 --province "สกลนคร" --max-riders 30
```

- ใช้งานได้ตลอด ไม่มีวันหมดอายุ
- รับอัปเดตได้ 1 ปี (`--years` เปลี่ยนได้) ถ้าติดตั้ง build ที่ออกหลังวันสิ้นสุด MA ระบบจะเป็นแบบดูข้อมูลได้อย่างเดียว จนกว่าจะต่อ MA หรือกลับไปใช้ build เดิม
- ต่อ MA: `node license-tool/hr-license.mjs renew HR-2026-0001`

## Subscription รายปี

```sh
node license-tool/hr-license.mjs issue --type subscription \
  --name "โรงพยาบาลตัวอย่าง" --hcode 10999 --province "สกลนคร" --max-riders unlimited
```

- ใช้งานได้ 1 ปีนับจาก `--start` (ค่าเริ่มต้นคือวันนี้)
- เตือนผู้ดูแลระบบล่วงหน้า 60 วัน หมดอายุแล้วใช้งานต่อได้อีก 30 วัน จากนั้นดูข้อมูลได้อย่างเดียว
- ต่ออายุ: `node license-tool/hr-license.mjs renew HR-2026-0002` (นับต่อจากวันหมดอายุเดิม ต่อก่อนกำหนดไม่เสียวัน)
- เปลี่ยนจาก subscription เป็นขายขาด: `renew HR-2026-0002 --type perpetual`

## งานประจำ

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `list` | รายชื่อลูกค้าเรียงตามวันสิ้นสุด แจ้ง "ใกล้หมด" ภายใน 60 วัน (`--days` เปลี่ยนได้) |
| `renew <เลขที่> [--years N] [--max-riders N]` | ออกไฟล์ใหม่เลขเดิม เพิ่มครั้งที่ (r2, r3, ...) |
| `verify <ไฟล์>` | ตรวจว่าไฟล์ออกจากกุญแจนี้และไม่ถูกแก้ |

ไฟล์ที่ต้องส่งให้ รพ. อยู่ใน `~/.health-rider-license/issued/` ผู้ดูแลระบบของ รพ. ติดตั้งที่ **ตั้งค่าระบบ > License**

## ระบบตรวจอะไรบ้าง

- ลายมือชื่อดิจิทัล (Ed25519) แก้ไฟล์แม้ตัวอักษรเดียวก็ใช้ไม่ได้
- ชื่อ รพ. ในไฟล์แสดงที่มุมซ้ายบนทุกหน้าและหน้าเข้าสู่ระบบ
- จำนวนไรเดอร์ที่เปิดใช้งาน (`--max-riders`) ตอนสร้าง อนุมัติ หรือเปิดบัญชีไรเดอร์
- โหมดดูข้อมูลได้อย่างเดียว ยังเข้าสู่ระบบ ติดตั้ง license และรับงานส่งยาที่ไรเดอร์ทำค้างไว้ได้เสมอ
